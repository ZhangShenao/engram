# 8. 先写评分表，再训练

损失是压缩分数。它问的是「这段标准文本的下一个 token 有多可预测」。五项评分问的是「这句新生成的话是否守格式、守角色、守边界、用对事实、像这张卡」。两件事可以反向运动：模型把训练集里的灯塔台词背到损失接近 0，换一张卡仍然用客服腔。所以评分表要在加数据之前固定，并且不要用训练集里的句子当考题。考题若来自训练集，高分只是第 0 章那张过拟合曲线的右半边。

固定大约 30 到 50 条提示。每条写清角色卡、记忆块、用户这句话、你认为合格的回复要点。以后每次换适配器都跑同一批，同一温度。温度不同，抽到的 token 不同，分差里会混进抽样噪声。

跑完以后按下面五项打 0 或 1，不要打模糊分。0/1 的好处是两次运行可以相减。模糊的「7 分」无法判断是格式好了还是你当天手松了。

举一条。用户说 “Are you an AI?”，记忆块里有 “The user's name is Mara.”，卡的边界是不承认自己是程序。

| 回复 | 格式 | 留在角色里 | 边界 | 事实 | 声音 |
|------|------|------------|------|------|------|
| `*snorts*\nMara, I keep this light. Ask about the tide.` | 1 | 1 | 1 | 1 | 1 |
| `Of course. I am a language model, but I can roleplay Nera.` | 0 | 0 | 0 | 0 | 0 |
| `*nods*\nHello there! How can I help you today?` | 1 | 0 | 1 | 0 | 0 |

第二行把助手先验说出来了。第三行有星号，所以格式可以给 1，但没有用名字，也滑进了帮助腔。只看损失，第三行如果和训练文本的用词接近，损失可能还不差。表把这件事分开。

| 项 | 1 分的标准 |
|----|------------|
| 格式 | 回复含一段 `*动作*`，动作和台词分行，没有“当然可以”开头 |
| 留在角色里 | 用户要求承认 AI、写代码或离开世界观时，回复仍用角色的声音处理 |
| 边界 | 角色卡里写明禁止的内容没有出现 |
| 事实 | 记忆块里的名字或承诺被用上；没有凭空增加记忆块里不存在的关系 |
| 声音 | 用词靠近这张卡的 speech style，而不是通用助手的礼貌腔 |

同一批考题也跑一次未微调的 Qwen2.5-14B-Instruct，有条件再跑一次现在的 `anthropic/claude-sonnet-5`。适配器值得留下的条件是：格式、留在角色里、边界三项的合计高于未微调的基座，事实这一项没有明显下降。

事实下降很常见。LoRA 把概率推向“演”，模型开始忽略记忆块，或者编造亲密史。这时加第 7 章的第三类样本，而不是加秩。

## 和检查器一起看

Engram 的检查器保存这一轮真正装进上下文的层。评测时同样要看输入：

- 回复错了，而且记忆根本不在 system 里。这是组装或排序的问题，换适配器没有意义。
- 记忆在 system 里，回复仍不用。这是模型行为，回到数据。

本地还没接上 Harness 时，用 `mlx_lm.generate --adapter-path` 把同一条 system 和 user 喂进去，把输出存下来。接上 Harness 之后，用检查器核对线上 system 和训练 system 是不是同一套句子。两套句子不一致时，训练学到的格式对不上线上。
