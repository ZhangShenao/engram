# 3. Transformer 里有什么

Qwen2.5-14B-Instruct 的配置是：48 层，隐藏维度 5120，40 个查询头，8 个键值头，头维度 128，前馈中间维 13824，激活是 SiLU。架构名是 `Qwen2ForCausalLM`。下面用这一组数字把参数对上账，避免“14B”停留在名字上。

第 0b 章的线性层 `y = Wx` 是这里每一块投影的形式。SiLU 是夹在前馈线性层之间的激活函数。注意力则是用点积决定每个 token 该看哪些位置。

## 一层里的顺序

一层先做注意力，再做前馈。两边都有残差：原来的向量一直留在一条干路上，子层只负责加上一份增量。

![一层 Transformer，从上往下读](images/03-transformer-block.jpg)

写成式子就是：

```text
x = x + Attention(RMSNorm(x))
x = x + SwiGLU(RMSNorm(x))
```

RMSNorm 把向量的尺度拉稳，本身参数很少，就是每个维度一个缩放。残差的意义很具体：深层网络如果只能整段重写 `x`，前面几层已经抽出的信息很容易被盖掉。加上残差之后，子层可以只修改需要改的方向。

48 层就是把这个方块堆 48 次。最后再过一次归一化，用输出矩阵投回 152064 维的词表 logits。logits 减去最大值再做 softmax，得到下一个 token 的概率。

## 因果注意力

注意力让当前位置去“查阅”别的位置。查询 Q、键 K、值 V 都是当前向量乘出来的三块线性投影。相关度来自 Q 和 K 的点积，取出来的内容是 V 的加权和。

生成是从左到右的，所以位置 t 不能看见 t 之后的 token。这靠一张下三角掩码实现，对角线保留，因为当前位置可以看见自己。

![因果掩码](images/04-causal-attention.jpg)

把一步注意力写成三行。每个 token 已经有了自己的向量。线性层分别乘出 Q、K、V。位置 `i` 对位置 `j` 的分数是 `Qi` 和 `Kj` 的点积，再除以 `√头维度`。Qwen 的头维度是 128，`√128 ≈ 11.3`。不除的话，128 个数的点积容易变得很大，Softmax 会饱和成几乎 0 和 1，梯度消失。除完之后对一行做 Softmax，得到「看每个位置多少比例」。输出是这些比例对 V 的加权和。

因果掩码发生在 Softmax 之前：未来位置的分数改成一个极小的负数，指数之后概率变成 0。对角线留下，因为当前位置可以看见自己。图里 t3 那一行因此是 t1、t2 和 t3 三格允许，t4 不允许。

用两个位置、头维度为 1 把掩码走完。设 `Q = (1, 1)`，`K = (1, 3)`，`√d = 1`。分数矩阵是 Q 乘 K：

| 查询 \\ 键 | t1 的 K=1 | t2 的 K=3 |
|------------|-----------|-----------|
| t1 的 Q=1 | 1 | 3 |
| t2 的 Q=1 | 1 | 3 |

掩码把 t1 对 t2 的分数 3 抹掉。t1 只能看见自己，注意力权重是 1。t2 看见两格，Softmax(`1`, `3`) 大约是 `0.12` 和 `0.88`，所以 t2 的输出主要来自 t2 自己的 V，同时带一点 t1 的 V。真实头维度是 128，算法相同，只是点积里有 128 项。

多头是把 5120 维拆开做几份注意力，再拼回去。40 个头，每头 128 维，`40 × 128 = 5120`。不同的头可以在同一次前向里看不同的对应关系，比如一个头更关注人名，另一个头更关注上一句的动词。这是训练出来的分工，不是代码里写死的岗位。

Qwen2.5-14B 使用分组查询注意力：40 个查询头，8 个键值头。每 5 个查询头共用一对 K、V。查询更细，键和值更省。省下来的主要是推理时的 KV cache，也就是已经算过的 K、V。生成第 100 个 token 时不必把前 99 个的 K、V 重算一遍，把它们存着即可。训练要反传，中间结果不能只靠这份缓存省掉。KV cache 是推理结构，不是你这次要训练的对象。

## 残差和 RMSNorm 在保护什么

残差写成 `x + 子层(x)`。子层输出如果接近 0，这一层就等于把 `x` 原样送下去。训练可以从「什么都不改」开始学，而不是每一层都被迫重写整份表示。48 层能叠起来，靠的是这条干路一直在。

RMSNorm 放在子层前面。它把向量除以自己的均方根，再乘上一组可学习的缩放。均方根是各维平方的平均再开方。向量整体被放大或缩小时，除完之后尺度回到同一量级，点积才不会跟着层数乱涨。可学习的缩放让模型还能把某些维重新放大。参数量是每个维度一个数，和 `5120 × 5120` 的投影比起来可以忽略。

## 前馈网络在每个位置单独做什么

注意力负责在 token 之间搬信息。前馈网络对每个位置单独做一次非线性变换，token 之间不再交换。SwiGLU 用三块矩阵：gate 和 up 把 5120 投到 13824，SiLU(gate) 和 up 逐元素相乘，down 再投回 5120。

```text
前馈(x) = down( SiLU(gate(x)) ⊙ up(x) )
```

`⊙` 是逐个位置相乘。gate 经过 SiLU 之后像一扇门：接近 0 的维把 up 的对应维压掉，接近 1 的维让它通过。中间维 13824 比 5120 宽，是先把表示摊开、做完筛选，再压回去。一个位置上的措辞习惯，很大一部分坐在这三块矩阵里。把「知识存在前馈里、对应关系存在注意力里」当成读结构的地图即可。它是研究里的一种图景，不是这三块矩阵在代码里写了注释。

## 参数账

一块线性层的参数量大约是输入维乘输出维。Qwen2.5 这些投影默认没有偏置，下面按无偏置估算。

一层注意力：

| 投影 | 形状 | 参数 |
|------|------|------|
| Q | 5120 × 5120 | 26,214,400 |
| K | 5120 × 1024 | 5,242,880 |
| V | 5120 × 1024 | 5,242,880 |
| O | 5120 × 5120 | 26,214,400 |

一层前馈：三块 `5120 × 13824`，合计 212,336,640。

一层合计约 2.75 亿。48 层约 132.1 亿。两块词表矩阵各约 7.79 亿。加起来约 147.7 亿。产品名叫 14B，配置摊开是这个量级。

这 147 亿个数字就是权重。微调如果要改它们全部，梯度和优化器状态会再复制几份。第 6 章用同一本账解释为什么 48 GB 只够训练其中的低秩增量。
